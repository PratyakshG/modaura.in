# 🛍️ Modaura – E-commerce Platform for Artificial Jewellery

Modaura is a full-stack e-commerce platform built for artificial jewellery. It offers a clean, responsive, and secure shopping experience featuring seamless browsing, cart management, checkout, payments, and order history.

## 🔗 Live Demo
www.modaura.in

## 🚀 Features

- 🖥️ Modern UI with **TailwindCSS** and **Shadcn UI**
- 🔐 Secure authentication with **NextAuth v5** (Google OAuth)
- 🛒 Dynamic cart with global state management using **Zustand**
- 💳 Payment integration with **Razorpay**
- 📦 Shipping and order tracking via **Delhivery API**
- 📧 Transactional emails through **Mailtrap**
- ✅ Form validation using **Zod** + **React Hook Form**
- 🧩 Modular components and clean architecture with **Next.js App Router**
- 🌐 Fully responsive across devices

## 🛠️ Tech Stack

- **Frontend:** Next.js 15 (App Router), TypeScript, TailwindCSS, Shadcn UI
- **Backend:** API Routes (Next.js), MongoDB (via Mongoose)
- **Authentication:** NextAuth v5 (Google OAuth)
- **State Management:** Zustand
- **Form Handling:** React Hook Form + Zod
- **Payments:** Razorpay
- **Emails:** Mailtrap
- **Shipping:** Delhivery API
